# 🍻 Guia de Botecos BH

Este projeto foi desenvolvido com fins exclusivamente educacionais.

A ideia surgiu de uma dor bem simples: o site oficial do evento não possui filtros práticos para busca de bares, e isso sempre foi motivo de reclamação entre amigos quando tentamos decidir para onde ir.

Como mineiro e apaixonado pela cultura de boteco, resolvi criar uma solução simples que facilitasse essa experiência — permitindo buscar bares por nome, dia de funcionamento, bairro e região.

---

## 💡 Objetivo

Criar uma interface leve e funcional que permita:

- Buscar bares pelo nome
- Filtrar por dia da semana
- Filtrar por bairro
- Filtrar por região
- Visualizar detalhes dos pratos e estabelecimentos

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (puro)

---

## ⚠️ Aviso

Este projeto não possui qualquer finalidade comercial.

Todas as informações apresentadas foram obtidas a partir do site oficial do evento, e todas as imagens pertencem aos seus respectivos proprietários.

---

## ❤️ Sobre o projeto

Mais do que um exercício técnico, este projeto também é pessoal.

Ele nasce do carinho pela cultura mineira, pelos encontros em bares e pelo próprio espírito do evento — que valoriza o que é simples, bem feito e cheio de história.
